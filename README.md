One picture, one joke: a proud little AI agent holds up the game it just shipped — a cartridge on fire — giving a thumbs up while the human developer facepalms beside it. "THE AGENT SHIPPED IT. NOBODY CAN PLAY IT. BUT IT SHIPPED."

## Run it

```sh
node main.ts
```

The program copies `entry.png` (1024x1024 PNG, 342,186 bytes) to `/output/entry.png`, checking first that it is a whole PNG within the 1 MiB and 1024x1024 gate. `MAKEFUN_OUTPUT_DIR` overrides `/output` outside the sandbox.
